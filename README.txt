CampusMate Mini Project — Version 1.0

OPEN
1. Extract the ZIP.
2. Open the CampusMate_Mini_Project folder.
3. Double-click index.html. It opens in Chrome, Edge, or another modern browser.

WORKING FEATURES
- Responsive dashboard and navigation
- Add/edit/delete/search/filter assignments; mark tasks complete
- Add/edit/delete weekly classes
- Attendance subject records, present/absent logging, and percentage calculations
- Create/edit/delete/search study notes
- Edit student name/course, switch dark mode, restore sample data
- Saves changes in browser localStorage after refresh

TECHNOLOGY
HTML5, CSS3, vanilla JavaScript, localStorage. This is a working client-side prototype, not yet a Flask server or SQLite database. It does not implement login, official college integration, or cross-device syncing. We can add a Python Flask + SQLite backend as the next phase if required.

EXAMINER DEMO
1. Add an assignment; refresh to demonstrate persistence.
2. Search/filter assignments and mark one complete.
3. Add a class and show the timetable.
4. Add an attendance subject; log present/absent and explain formula: present / (present + absent) * 100.
5. Create, search, edit, and delete a note.
6. Change profile and toggle dark mode.
7. Explain the HTML structure, CSS responsive layout, JavaScript event handlers, and localStorage.
